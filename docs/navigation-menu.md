# NavigationMenu

Main navigation menu with dropdowns.

## Import

```tsx
import { NavigationMenu, NavigationMenuList, NavigationMenuItem } from '@flavioespinoza/salsa-ui'
```

## Usage

```tsx
<NavigationMenu>
  <NavigationMenuList>
    <NavigationMenuItem>Home</NavigationMenuItem>
  </NavigationMenuList>
</NavigationMenu>
```
