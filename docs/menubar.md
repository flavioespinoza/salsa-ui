# Menubar

Desktop application style menu bar.

## Import

```tsx
import { Menubar, MenubarMenu, MenubarTrigger, MenubarContent } from '@flavioespinoza/salsa-ui'
```

## Usage

```tsx
<Menubar>
  <MenubarMenu>
    <MenubarTrigger>File</MenubarTrigger>
    <MenubarContent>...</MenubarContent>
  </MenubarMenu>
</Menubar>
```
