# Collapsible

Expandable and collapsible content section.

## Import

```tsx
import { Collapsible, CollapsibleTrigger, CollapsibleContent } from '@flavioespinoza/salsa-ui'
```

## Usage

```tsx
<Collapsible>
  <CollapsibleTrigger>Expand</CollapsibleTrigger>
  <CollapsibleContent>Hidden content</CollapsibleContent>
</Collapsible>
```
